# 音乐与影视喜欢次数统计分析

## 问题与需求

站点维护者需要了解音乐与影视收藏中已记录的喜欢次数分布，以及高喜欢次数条目在各自收藏中的占比，以便回顾个人偏好。现有页面提供单条次数展示和排序，但缺少直观的整体统计分析。

用户要求以图表呈现统计分析，范围同时包含音乐和影视；本条目仅记录需求，不授权实现。

## 验收标准

- [ ] 音乐和影视均可查看基于已记录喜欢次数的图表统计。
- [ ] 可查看喜欢次数分布、高喜欢次数条目及其占比；统计结果与原始数据一致。
- [ ] 音乐与影视分别统计，明确显示统计范围与口径，包括占比分母和高喜欢次数条目的选取规则。
- [ ] 仅有累计次数时，不推断喜欢发生的时间趋势；发行或上映日期不作为喜欢日期。
- [ ] 统计入口默认收起，展开不离开收藏页；图表随原有筛选变化，排序不改变统计结果，柱选择不改变分析基准。
- [ ] 高喜欢次数条目按已确认设计的阈值与并列规则展示；无条目、全同次数和异常次数均有明确状态，不生成误导结论。
- [ ] 图表同时提供可读取的数值和数据表，键盘及移动端均可使用。

## 已确认设计

用户已确认[音乐与影视喜欢次数统计设计](../design/like-count-analytics.md)，该文档维护图表类型、入口位置、指标公式、阈值、并列规则、筛选联动及边界状态。

当前仍为需求记录与设计阶段，未实现、未完成验收；保留 `status: captured` 和 `priority: unset`，不据设计确认自动推进开发或安排优先级。
